### 🚀 Featured Projects

#### 📓 Daily Ink — a private daily journal

<p>
  <img src="https://img.shields.io/badge/React%2019-20232A?style=flat-square&logo=react&logoColor=61DAFB" alt="React 19" />
  <img src="https://img.shields.io/badge/Vite-646CFF?style=flat-square&logo=vite&logoColor=white" alt="Vite" />
  <img src="https://img.shields.io/badge/Tailwind%20CSS-06B6D4?style=flat-square&logo=tailwindcss&logoColor=white" alt="Tailwind CSS" />
  <img src="https://img.shields.io/badge/Supabase-3FCF8E?style=flat-square&logo=supabase&logoColor=white" alt="Supabase" />
  <img src="https://img.shields.io/badge/PWA-5A0FC8?style=flat-square&logo=pwa&logoColor=white" alt="PWA" />
</p>

Write one page a day. Daily Ink keeps the streak, resurfaces what you wrote on this date in past years, and schedules reviews on a spaced-repetition ladder (1 → 3 → 7 → 14 → 30 days) so old entries stay memorable. It installs as a PWA and keeps working offline.

- **Frontend** — React 19, Vite and Tailwind CSS; installable PWA with a service worker and an offline app shell.
- **Data & auth** — Supabase Postgres with row-level security on every table, username-based sign-in, realtime cross-device sync, optional AES-256-GCM encryption, and JSON/Markdown export.
- **Logic & tests** — date math, streaks and the review scheduler live in a small Rust core compiled to WebAssembly, exercised by `npm test`.
