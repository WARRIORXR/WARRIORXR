### 🚀 Featured Projects

#### 📓 Daily Ink — a private journal that does the math

A private journal PWA: write one page a day, and the app keeps the score. Streaks, memories and review scheduling all run on real date and statistics logic. Stack: React, Vite, Tailwind CSS, Supabase (PostgreSQL, Auth, Realtime).

- **Streak analytics** — current, longest and total streaks with a weekly freeze, computed in a Rust core.
- **Spaced repetition** — a standard SM-2 scheduler (ease factor, growing intervals, due queue) that resurfaces old entries for review.
- **Writing dashboard** — a 53-week writing heatmap, word-count and reading-time stats, a mood map, and "On this day" memories.
